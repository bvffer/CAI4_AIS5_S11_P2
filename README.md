# Customer Data ETL Pipeline — Presentation

A 28-slide click-through presentation deck built with Next.js and Framer Motion, covering the full CRM ETL pipeline project — from fragmented CSV sources to a clean, trusted PostgreSQL database.

## Live Demo

[**View the presentation on Vercel**](https://workspace-5e19c13b-3602-4c0f-9214-0.vercel.app)

## Tech Stack

- **Next.js 16** (App Router)
- **Framer Motion** (slide transitions)
- **Tailwind CSS** (styling)
- **TypeScript**

## Navigation

- Arrow keys (← → ↑ ↓) or Space/PageUp/PageDown
- Click left/right edges (4vw zones)
- Bottom nav buttons
- Touch swipe
